# Heroes of Light

A Christian fighting platformer you play in the web browser, on a computer or a phone.

Eight friends cross five lands, meet friends from church along the way, and defeat Satan together to free the church on the hill.

## Play

Open `index.html` in a browser, or play the GitHub Pages version of this repository.

On iPhone, open the link in Safari and turn the phone sideways. For full screen, tap Share, then "Add to Home Screen".

## Controls

| Action  | Keyboard         | Phone       |
|---------|------------------|-------------|
| Move    | Arrow keys / A D | ◀ ▶ buttons |
| Jump    | Space / Up / W   | JUMP        |
| Attack  | J or X           | ATK         |
| Skill 1 | K or C           | S1          |
| Skill 2 | L or V           | S2          |
| Pause   | Esc / P          | II          |

The whole game is one file, `index.html`, with no build step.
